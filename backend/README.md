# Бэкенд приёма заявок → MAX

Маленький сервис без зависимостей: принимает заявку с лендинга, сохраняет её
в журнал `leads.jsonl` и присылает уведомление менеджеру в мессенджер MAX.

```
Форма на сайте  →  POST /lead  →  server.js  ─┬─→ запись в leads.jsonl
                                              └─→ бот MAX пишет менеджеру
```

## Что нужно один раз сделать (ручные шаги в MAX)

1. **Создать бота.** В MAX найти **@MasterBot**, нажать «Начать», отправить `/create`,
   придумать ник (заканчивается на `bot`) и отображаемое имя. MasterBot пришлёт **токен** —
   это секрет, вставить в `.env` как `MAX_TOKEN`.
2. **Менеджер пишет боту.** Тот, кому должны падать заявки, открывает бота и жмёт «Начать».
   Бот не может написать первым — это ограничение MAX (как в Telegram).
3. **Узнать user_id менеджера:**
   ```bash
   MAX_TOKEN=ваш_токен node capture-id.js
   ```
   Скопировать показанный `user_id` в `.env` как `MANAGER_USER_ID`.

## Сертификаты Минцифры (важно!)

MAX перешёл на российские сертификаты, которые Node по умолчанию не доверяет —
без этого шага запросы к API упадут с TLS-ошибкой. На сервере:

1. Скачать корневой и промежуточный сертификаты Минцифры с https://www.gosuslugi.ru/crt
   (или https://gu-st.ru/content/lending/) и склеить в один файл `russian-ca.pem`.
2. Прописать путь к нему в `.env`: `NODE_EXTRA_CA_CERTS=/opt/perfecto/russian-ca.pem`.

## Запуск

```bash
cp .env.example .env      # заполнить значения
node --env-file=.env server.js
```

Для постоянной работы — под pm2 или systemd:
```bash
npm i -g pm2
pm2 start server.js --name perfecto-lead --node-args="--env-file=.env"
pm2 save && pm2 startup
```

Проверка: `curl http://localhost:8787/health` → `ok`.

## Подключение сайта

После деплоя вписать URL сервиса в `index.html`, переменная `LEAD_ENDPOINT`
в начале `<script>` (например `https://ваш-сервер.ru/lead`). Пока переменная пустая —
сайт работает как раньше (показывает «заявка принята» + кнопку скачивания гида),
просто не отправляет заявку в MAX.

## Где это разместить

Нужен хост, с которого доступен `platform-api2.max.ru` и где можно поставить
сертификаты Минцифры — надёжнее всего **недорогой российский VPS** (Timeweb,
Selectel, Reg.ru; ~150–300 ₽/мес). Бесплатные западные serverless (Cloudflare
Workers, Vercel) не подойдут: их нельзя научить доверять российским сертификатам,
и до API MAX они, скорее всего, не достучатся.

## Примечание

Bot API MAX в активной фазе изменений (июль 2026: миграция домена, смена
сертификатов). Если что-то отвалится — сверяться с актуальной документацией
https://dev.max.ru/docs-api
